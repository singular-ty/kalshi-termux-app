          How to get a Kalshi API key
          
    
            
  1. Log in → profile/account → API Keys → Create New API Key.
    2. 
            
  2. Save the Key ID and download the PEM immediately; the private key cannot be retrieved later.
    3. 
            
  3. Paste the Key ID + PEM here → Save encrypted (or use .env + secrets/kalshi.key).
    4. 
            
  4. After the new key works, revoke old keys in the same API Keys list (delete/revoke).
    5. 
          

          
Kalshi API key documentation: docs.kalshi.com/getting_started/api_keys

        

        
        
        
        
        
Accepted PEM headers: BEGIN RSA PRIVATE KEY and BEGIN PRIVATE KEY. Never paste a key into source control or chat.
