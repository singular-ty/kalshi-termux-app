How to trade

        
    
          
  1. Set an app lock password and tap Unlock.
    2. 
          
  2. Paste your Kalshi Key ID and private key text, then Save on this phone.
    3. 
          
  3. Open Account and check Balance.
    4. 
          
  4. Use Scan. Paper bets (no money) are optional and do not spend anything.
    5. 
          
  5. For real bets (uses Kalshi balance): tap Allow live trading, then type ARM LIVE.
    6. 
        

      


      

        
Trading mode

        

          Paper bets (no money)
          
Orders stay on this phone. Tap Allow live trading when you want real bets.

        

        

          
          
        

        
Allow live trading does not place an order. You still type ARM LIVE before the first real bet. No .env edit needed.

      


      

        
Turn on real orders (extra step)

        
After Allow live trading, type ARM LIVE once. Then Place bet can spend your Kalshi balance. Disarm stops real orders until you arm again.

Kalshi key

          No keys
        

        
This phone does not come with a key. Paste yours here. Scanning markets works without one.

        

          How to get a Kalshi API key
          
    
            
  1. Log in → profile/account → API Keys → Create New API Key.
    2. 
            
  2. Save the Key ID and download the private key immediately. Kalshi will not show it again.
    3. 
            
  3. Paste the Key ID and private key text here → Save on this phone.
    4. 
            
  4. After the new key works, revoke old keys in the same API Keys list (delete/revoke).
    5. 
          

          
Kalshi API key documentation: docs.kalshi.com/getting_started/api_keys

        

        
        
        
        
        
The text usually starts with -----BEGIN RSA PRIVATE KEY----- or -----BEGIN PRIVATE KEY-----. Never paste a key into source control or chat.

        

          
          
        

        
This only removes the key from this phone. It does not revoke the key on Kalshi. Revoke it separately at Kalshi.com.
